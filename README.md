Download the main files here. For emulator users, I highly recommend compiling the mod into a cia. For hardware users, you NEED to: no exceptions. Placing the files like you're using an emulator will cause massive lag and the game will be unplayable. Read the instructions in the zip files carefully.

Modpack will be stuck in v.22 until Secret Path is completed. You will overwrite base VOW with the modpack files given, if you want to use it.

Install Instructions:
Emulators
- AppData\Roaming\Citra\load\mods\0004000000179800. If you are not going to compile this mod, take the contents of the zip file in the github and place them in the 179800 folder. 
Hardware
- luma\titles\0004000000179800. Hardware MUST compile this mod into a cia or else you will get a lot of lag. If you are using modpack, the romfs/sound/stream folder must be externally loaded with Luma3ds
